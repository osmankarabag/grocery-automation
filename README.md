# 🛒 Bakkal Otomasyonu

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

Küçük bir bakkalın ürün, veresiye ve gelir kayıtlarını tutan konsol uygulaması.

## ✨ Özellikler
- Ürün ekleme, güncelleme, arama ve silme (barkod ile)
- Müşteri bazlı veresiye borç hesaplama
- Aylık gelir hesaplama
- Veriler CSV/TXT dosyalarında saklanır

## 📁 Klasörler
| Klasör | Açıklama |
|---|---|
| `BakkalOtomasyonu` | CSV tabanlı sürüm |
| `BakkalOtomasyonu2` | TXT dosyası tabanlı ilk sürüm |

## ▶️ Çalıştırma
```bash
cd BakkalOtomasyonu
python bakkalotomasyon.py
```
